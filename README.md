## Viewing on GitHub

Open any linked Markdown page to read its rendered content and Mermaid diagrams directly in GitHub. Every documentation directory has a README landing page, so browsing folders also presents navigation. No local documentation server or GitHub Pages deployment is required.

The main guide and section indexes remain the authoritative reading paths. These README pages provide browser navigation without duplicating the detailed chapters.

## Source and scope

- This is a **private, documentation-only repository**. It does not contain or run the application.
- Source baseline: [`corelogic-private/real_estate_us-realist-phoenix` at `a6f611ae0`](https://github.com/corelogic-private/real_estate_us-realist-phoenix/tree/a6f611ae0654e2bf62deec0a7d5c1d333348d6be).
- Source-file links are pinned to that revision and require access to the private application repository.
- Backtick source paths and application commands refer to the application checkout, not this documentation checkout.
- Unknown provider implementations, deployed settings and the unlocated shared-report recipient reader are described in [known gaps and team questions](kt-docs/onboarding/known-gaps-and-team-questions.md).
