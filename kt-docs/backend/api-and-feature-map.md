## How to read the contracts

* **Browser** means the verb issued by the identified TypeScript service, image request, navigation or form. A service method's existence does not prove every UI branch currently invokes it.
* **U** means `@RequestMapping` has **no HTTP-method restriction**. It does **not** mean GET. Request-body binding, content type, authentication, profile and authorization constraints still apply.
* Paths below are **composed paths**: e.g. `PropertyIntelligenceController`'s `/api/property-intelligence` plus `/market-trends-charts`, not two independent URLs. Curly braces denote MVC path variables; lists of suffixes are explicitly scoped to the prefix printed in the same row.
* **Untraced** means no current browser call was established in this focused check; it does not prove that a partner, server-generated page or other client never calls it.

**Source-key convention:** `W` = `realist\web\src\main\java\com\facl\uaf\realist\`; `R` = `W` + `rest\controller\`; `C` = `W` + `controller\`; `F` = `phoenix\src\app\`. Thus `R SearchController.java:58` is the exact repository-relative source `realist\web\src\main\java\com\facl\uaf\realist\rest\controller\SearchController.java:58`. These prefixes apply to all source references below.

In compact multi-reference cells, subsequent unprefixed TypeScript paths also start at `F`; bare `preference.service.ts`, `search.service.ts` and `map.service.ts` mean `F search\services\` plus that filename, and bare `whatIsNew.service.ts` means `F shared\services\whatIsNew.service.ts`. Subsequent bare Java controller filenames start at `R`; `ReportPdfService.java` means `W service\reports\pdf\ReportPdfService.java`. These are source-path abbreviations, not additional modules.

## Corrections and unresolved edges worth retaining

1. **Spatial bounding-box verb mismatch in a service helper.** `F reports\services\reports.service.ts:296` issues POST with a property identifier, but `R MapController.java:176-205` exposes GET with `width`, `height`, `layers`, `styles`, `bbox` query parameters. A distinct map-tile URL is constructed at `F reports\components\flood-map-report\flood-map-report-map\flood-map-report-map.component.ts:111`. Therefore a valid tile-image GET path can coexist with a stale/incompatible helper. The helper's live call chain was not established; do not claim every flood-map request fails, or that POST is accepted here.
2. **Unmatched browser helper paths.** `F search\services\map.service.ts:51` POSTs `/api/reverselinkURL`, whereas this host inventory maps `/api/reverselinkURL-grid` (`R LoginAllData.java:149`). `F orders\services\orders.services.ts:97` POSTs `/api/store/set-default-card`, for which no mapping was found in the host controller inventory. Treat both as unresolved/possibly stale helpers, not documented working endpoints.
3. **Remote and local cart deletion are different.** Normal get/update/submit uses remote `StoreApiClient` (`R StoreController.java:337-355,478-487,681-705`). The separately exposed GET `/api/store/delete-cart` calls local `CartService.deleteCart` (`:737-741`), whose implementation calls `CartRepository.deleteAll` (`W rest\service\CartService.java:102-104`). No current browser caller was established; do not present this route as the normal “clear my remote cart” operation.
4. **Prepared files are not durable shared links.** PDF preparation/cache keys and later rendering are in `W service\reports\pdf\ReportCachingService.java:32-70,112-114` and `ReportPdfService.java:72-100`. Durable snapshots are persisted separately by `W rest\service\sharedlink\SharedLinkService.java:70-145`; its recipient URL is constructed from a configured public base (`:168-179`). No recipient-read controller was found in this host inventory; recipient hosting/runtime is not verified.
5. **Passing a session ID does not itself scope Redis keys.** `uaf-common\action\src\main\java\com\facl\uaf\common\shared\util\LocalStorage.java:37-49,56-83` writes the supplied key with TTL and explicitly warns that the `sessionId` argument does not namespace the key. PDF keys add user identity and unique name; CSV uses its generated filename. Consult [Redis/sessions](../cross-cutting/redis-caching-and-sessions.md) before asserting isolation or lifetime.
6. **Do not infer architecture from one happy path.** Search can call `PropertySearchAction`/`PropertySearchDelegate` directly; analytics uses common services; commerce/PDF use direct clients; sharing uses repositories. `ServiceHandler` is not universal. No inbound GraphQL/DGS controller is established by this inventory.
